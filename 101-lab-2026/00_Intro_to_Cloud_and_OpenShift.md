# Cloud platforms in BC Government

Within the BC Government, there are two broad offerings for cloud hosting available. 

## Private Cloud 
The private cloud offering is OpenShift. OpenShift is a variant of Kubernetes created and maintained by RedHat. The majority of these services run on servers based in Kamloops, with an option for geographic failover to servers in Calgary. 

This training focuses on OpenShift.

## Public Cloud
The public cloud offers services from Amazon Web Services (AWS) and Microsoft Azure. These services are outside the scope of this training.
