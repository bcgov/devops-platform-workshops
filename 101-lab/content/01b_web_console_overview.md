# OCP 4 Web Console

If you have previous experience with an old version of Openshift (version 3) the web console is going to look very different
to what you are used to. 

## Highlights

From version 4.20, the web console combines the interfaces that previously divided into 'developer view' and 'administrator view'. Keep this in mind if you see older documentation that references these views.
